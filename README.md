# NetParGolf

**Score • Setup • Compete**

NetParGolf is a golf scoring and competition companion designed for golfers, societies, and club competitions.

Track your rounds, manage course data, and calculate competition handicaps — all from one app.

## Features

### Live Scoring

Supports:

* Individual Stableford
* Betterball Stableford
* Match Play

Track scores hole-by-hole and view live standings throughout the round.

### WHS Handicap Calculations

Calculate:

* Course Handicap
* Playing Handicap
* Competition Allowances
* Stroke Allocations

### Competition Handicap Checker

Create competition handicap sheets for teams and groups.

Ideal for:

* Golf societies
* Club competitions
* Captains' days
* Charity events

### Course Management

Create and manage golf courses with:

* Tee information
* Course Rating
* Slope Rating
* Hole Pars
* Stroke Index values

### Round History

Store and review completed rounds.
